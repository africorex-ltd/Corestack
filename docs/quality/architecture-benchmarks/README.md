# Architecture Benchmark Reports

Periodic per-subsystem structure reports (maturity policy §11.2): complexity,
coupling, cohesion, dependency count, public-API growth, test growth —
`<subsystem>-<date>.md`, generated at epic exits alongside the Engineering
Health Report, first real report at E03 exit. Trends matter more than
absolutes: every report links its predecessor and explains deltas. Package
scorecards (testability/maintainability/docs/perf/security/API-stability)
summarize into the health report per §11.3.
