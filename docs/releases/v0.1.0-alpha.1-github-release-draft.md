**Body:**

```markdown
First alpha of CoreStack's foundation layer — a zero-runtime-dependency
kernel, a Postgres-first platform package, and a certified tenant-isolation
stack. No product module ships yet; this is the base E05 (Tenancy) builds on.

## Highlights

- 8 kernel ports (Cache, RateLimiter, Logger, EventBus, UnitOfWork,
  Encrypter, ProcessedEventStore, IdempotencyStore), each with an
  executable contract suite proven against every real adapter.
- Full transactional outbox, migration engine, RLS-based tenant isolation
  (certified with residual risks), config validation, health/readiness.
- A golden-path example module proving every tenant-isolation touchpoint
  end-to-end against real PostgreSQL 18.
- 461 tests, zero mocked Postgres behavior — every database claim is
  verified against a real instance.

## Not included

No HTTP layer, no authentication, no product feature module. Not for
production use — see [readiness review](docs/releases/v0.1.0-alpha-readiness.md).

## Security

ADR-0020 and ADR-0022 fixed two real findings during development (a
cross-tenant idempotency-key replay, never exposed to a real caller; and
a Logger redaction gap). Full posture: certified with residual risks —
see [tenant-isolation-certification.md](docs/security/tenant-isolation-certification.md).

## Full changelog

See [CHANGELOG.md](CHANGELOG.md)'s `[Unreleased]` section — the complete,
commit-by-commit record this release train cuts from.
```
